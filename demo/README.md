This standalone, synthetic educational demonstration is separate from the commercial application. It accepts no files, has no external requests, and uses only fictional risk records.

1. Open [ScopeLedger_Demo.html](ScopeLedger_Demo.html) on GitHub.
2. Download the raw file and open it in a supported local browser.
3. Select a fictional review case, apply a review decision and inspect the queue. The example intentionally treats an unconfirmed or accepted issue as distinct from verified remediation.
