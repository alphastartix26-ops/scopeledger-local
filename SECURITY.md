# Security and responsible use

ScopeLedger is for authorized defensive security review only. This public repository contains documentation and a synthetic educational exercise, not the commercial application.

Never submit customer data, credentials, raw security reports, private paths, payment information or vulnerability details in public issues. A private, verified seller support and vulnerability-reporting channel will be provided before paid release. Until then, use synthetic data for public evaluations.

The development candidate is single-operator, local-first and not certified or independently audited. Scanner adapters, feed adapters and local model adapters have integration limits. Verify real scanner/model versions, evidence scope, output handling, OS-level access and egress controls before using sensitive information. Backup encryption protects exported vault files only, not every file or the open session. Do not bypass browser security controls.
