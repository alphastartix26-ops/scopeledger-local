# ScopeLedger Executive · 한국어

**로컬 보안 검토 및 경영진 위험 관리 도구 — v0.2.0 개발 프리뷰**

허가된 프로젝트의 설정 검사 결과와 외부 보안 검사 보고서를 자산별 위험 등록부로 통합하고, 책임자·개선 기한·위험 수용 판단을 정리할 수 있도록 설계했습니다.

| 기능 | 범위 |
| --- | --- |
| 보안 검토 | 22개 휴리스틱 설정 검사 규칙 |
| 보고서 통합 | SARIF 2.1.0, Trivy JSON schema 2, Gitleaks JSON 등 제한된 형식 |
| 위험 관리 | 자산 중요도, 담당자, 기한, 상태, 위험 수용 재검토 |
| 경영진 보고 | 자산 별칭을 사용한 HTML 요약, 내부용 CSV·JSON |
| 실행 방식 | 외부 서비스가 필요 없는 단일 운영자 로컬 세션, 수동 백업 |

[합성 데이터 보고서](SAMPLE_EXECUTIVE_REPORT.md) · [영문 소개](README.md)

일회성 상업용 라이선스를 준비 중입니다. 현재 결제 및 유료 배포는 시작하지 않았으며, 전체 제품 소스는 이 공개 저장소에 포함되지 않습니다.

실제 기업 도입·독립 보안 감사·기업 인증은 검증되지 않았습니다. 중앙 권한 관리, SSO/RBAC, 중앙 암호화 저장소, 실시간 CVE 피드 및 인증된 다중 사용자 감사는 제공하지 않습니다. 외부 검사기를 직접 실행하는 제품이 아니며, 가져온 기록 수는 확정 취약점 수와 다를 수 있습니다. 체크섬은 디지털 서명이 아닙니다.
