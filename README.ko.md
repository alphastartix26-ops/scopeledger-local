# ScopeLedger Executive · 보안 위험 의사결정 콘솔

**v0.6.1 개발 후보 · 단일 운영자 로컬 제품 · 일회성 결제 예정**

보안 검사 결과를 단순 나열하지 않고 자산별 조치 우선순위, 반복 관측, 책임자, 개선 기한, 위험 수용, 등록된 자산 의존 관계, 경영진 보고서로 연결합니다.

[무료 합성 체험](demo/README.md) · [실제 프로그램에서 내보낸 합성 보고서 요약](samples/EXECUTIVE_V061.md) · [평가판 및 구매 가능 여부 문의](https://github.com/alphastartix26-ops/scopeledger-local/issues/new?template=evaluation.yml)

- 설정 검사 규칙 22개, 제한된 SARIF/Trivy/Gitleaks 가져오기, 별도 설치된 Trivy/Gitleaks/Bandit 실행 연결부
- 정확히 일치하는 Trivy 관측의 통합, 설치·수정 버전, CVSS/EPSS/KEV 및 NVD 데이터 연결부
- 담당자·기한·위험 수용·재검토, 재검사 관측 비교
- 운영자가 등록한 의존 관계 및 영향 검토 지도
- 규칙 기반 대응 분석과 선택적 로컬 AI 연결부
- 영문 경영진 HTML·내부 CSV·AES-256-GCM 암호화 백업 및 현재 작업 대조

초기 판매가는 59,000원 상당의 일회성 결제로 계획 중입니다. 현재 결제는 비활성화되어 있으며 문의는 무료·비구속적입니다. 실제 상점 승인, 제품 허용 확인 및 구매자 전달 검증 전에는 결제를 받지 않습니다.

기업용 SSO/RBAC·중앙 저장소·불변 인증 감사·SIEM/EDR는 미구현입니다. 실제 외부 검사기·공식 피드·로컬 AI 추론·Windows/기업 환경 및 브라우저 보안 컨텍스트 암호화 UI 성공 경로는 미검증입니다. 규칙 기반 검토는 보안 인증이나 침해 판정이 아닙니다. 합성 데모만 공개하고 전체 유료 실행본·원본 소스는 게시하지 않습니다.

## 최신 개발 후보: AI 보안 출시 검토

v0.9.0은 garak·Promptfoo·ModelScan 보고서 가져오기, 실패·오류·미평가 구분, 조건부 기준본 비교, 수동 출시 검토와 기존 위험 등록부 연결 기능을 추가했습니다. [기술 자료 및 원천 검토 기록](docs/AI_SECURITY_REVIEW.md). 실제 외부 도구의 실행 결과·호환성은 미검증이며, 합성 입력으로 기능을 검증했습니다. 별도 v0.8 팀 저장소의 접근통제·TOTP·암호화 복구는 기존 후보에 유지되며 통합 기업 운영은 아직 검증되지 않았습니다. 기존 무료 체험은 이전 워크플로 예시입니다. 결제는 비활성 상태입니다.
