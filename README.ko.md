초기 판매가는 59,000원 상당의 일회성 결제로 계획 중입니다. 현재 결제는 비활성화되어 있으며 문의는 무료·비구속적입니다. 기존 설명의 방어용 제품에 대한 판매 플랫폼 지원 회신은 확인했으나 판매자 설정, 최종 제품 범위 및 구매자 전달 검증 전에는 결제를 받지 않습니다.

단일 운영자 콘솔과 별도 팀 저장소는 아직 직접 통합되지 않았습니다. 별도 v0.8 후보에 작업공간 ACL·TOTP·암호화 복구가 구현됐으나 기업용 SSO·외부 불변 감사·실제 SIEM/EDR 수신 연동은 미완료입니다. 실제 외부 검사기·공식 피드·로컬 AI 추론·Windows/기업 환경 및 브라우저 보안 컨텍스트 암호화 UI 성공 경로는 미검증입니다. 규칙 기반 검토는 보안 인증이나 침해 판정이 아닙니다. 합성 데모만 공개하고 전체 유료 실행본·원본 소스는 게시하지 않습니다.

## 최신 개발 후보: AI 보안 출시 검토

v0.9.0은 garak·Promptfoo·ModelScan 보고서 가져오기, 실패·오류·미평가 구분, 조건부 기준본 비교, 수동 출시 검토와 기존 위험 등록부 연결 기능을 추가했습니다. [기술 자료 및 원천 검토 기록](docs/AI_SECURITY_REVIEW.md). 실제 외부 도구의 실행 결과·호환성은 미검증이며, 합성 입력으로 기능을 검증했습니다. 별도 v0.8 팀 저장소의 접근통제·TOTP·암호화 복구는 기존 후보에 유지되며 통합 기업 운영은 아직 검증되지 않았습니다. 기존 무료 체험은 이전 워크플로 예시입니다. 결제는 비활성 상태입니다.

### v0.9.1 증적 판정 개선

Promptfoo의 보고서 스키마, 보고된 내보내기 도구 버전, 캐시 결과 수를 분리합니다. 버전이나 캐시 수가 누락되거나 캐시 결과가 있으면 보수적으로 HOLD 처리하며 캐시된 정상 결과를 실패로 바꾸지 않습니다. 내보내기 버전이나 캐시 0은 실제 평가 버전·신규 추론을 증명하지 않습니다. [검증된 기술 설명](docs/AI_SECURITY_REVIEW.md#why-a-passing-ai-evaluation-is-not-necessarily-fresh-evidence).
