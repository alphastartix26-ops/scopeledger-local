## 2026-11-27 판매 현황

초기 상용 로컬 에디션을 판매 개시했습니다. 44달러는 세금 별도 기준이며 현지 통화 환산액은 결제 화면을 따릅니다. 구매 ZIP에는 단일 HTML 앱, 시작 안내, 지원 형식·AI 검토 안내, 합성 SARIF 샘플, 이용·지원 조건, 검증 기록 및 SHA-256 목록이 들어 있습니다. 앱 이용에 유료 API·모델·구독은 필요하지 않습니다.

한 명의 운영자가 허가된 내부/고객 프로젝트 증적을 검토하고 생성 보고서를 상업적으로 사용할 수 있습니다. 소프트웨어 재배포·재판매·여러 운영자 공유는 포함되지 않습니다. 구매 영수증 회신으로 30일간 설치·결함 지원과 14일 환불 요청을 받을 수 있으며 강행 소비자 권리를 제한하지 않습니다.

무과금 판매자 테스트 결제와 영수증의 ZIP 75,516바이트 첨부를 확인했습니다. **영수증 다운로드 파일의 바이트 대조는 아직 미완료**입니다. 판매자 브라우저가 파일 서버 요청을 차단했습니다. 테스트 주문은 실제 고객 구매·매출·정산이 아닙니다.

## 검증 범위

이번 Windows/Node.js 24.19.0 실행에서 엔진 회귀 **296/296**, 압축파일 검증 **9/9**가 통과했습니다. 최종 HTML의 스크립트 구문과 동봉 SARIF 샘플의 엔진 처리를 확인했습니다. 원본 소유자/평가판의 내부 해시도 대조했습니다.

**최종 패키지의 Windows 브라우저 UI 및 암호화 저장·대조·복원 UI는 미검증입니다.** 도구가 로컬 파일 열기를 차단했으며 우회하지 않았습니다. Node 암호화 테스트는 브라우저 검증을 대신하지 않습니다. 원본 v0.9.2에 있는 과거 Chromium 합성 UI 40개 통과 기록을 이번 검증으로 재집계하지 않습니다.
